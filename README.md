# PanelKomplekt

Плагин для **AutoCAD 2021**: раскладка сэндвич-панелей по фасадам и спецификация.
После установки в AutoCAD появляется вкладка **PanelKomplekt** с кнопками команд.

Текущая версия и изменения — в [CHANGELOG.md](CHANGELOG.md). Незнакомые слова — в [словаре терминов](Docs/Glossary.md).

---

## Для пользователя AutoCAD

### Установка
1. Закройте AutoCAD.
2. Распакуйте архив `PanelKomplekt-<версия>.zip` целиком.
3. Дважды щёлкните `Install.cmd` и ответьте «Да» на вопрос Windows.
4. Запустите AutoCAD 2021 — на ленте появится вкладка «PanelKomplekt».

### Что умеет плагин
| Раздел | Кнопка | Что делает |
|---|---|---|
| Сервис | О плагине | Показывает окно со сведениями: версия, для кого и кем создан плагин, технологии. |
| Элементы | Поиск | Показывает ID выбранного элемента чертежа (тестовая). |
| Панели | Создание | Создаёт панели: массив вдоль линии по заданным параметрам или по одной панели двумя точками. Марка «буква + длина в см» обновляется сама при растягивании и копировании. |
| Панели | Проверка | Добавляет блок панели в чертёж и показывает данные выбранных панелей (служебная). |
| Спецификации | Составить | Считает панели на чертеже и сохраняет спецификацию в Excel и/или вставляет таблицу в чертёж. |

Пошаговое описание каждой команды, обновление, удаление и решение проблем — в **[руководстве пользователя](Docs/UserGuide.md)**.
