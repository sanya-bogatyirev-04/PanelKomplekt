# Словарь терминов

Термины, которые встречаются в документации и коде проекта. Сначала — предметные, затем — AutoCAD, затем — разработка.

## Предметная область
| Термин | Что означает |
|---|---|
| Сэндвич-панель | Готовая панель для стен или кровли: два металлических листа и утеплитель между ними. |
| Фасад | Наружная стена здания; на чертеже — развёртка стены с проёмами. |
| Проём | Окно, дверь или ворота в стене; панели в этом месте не ставятся или режутся. |
| Раскладка (раскрой) | Размещение панелей на площади фасада: сколько панелей, какой длины и где. |
| Монтажная ширина | Рабочая ширина панели без учёта замка, по ней считается раскладка. |
| Марка панели | Условное обозначение панели определённого типа и размера (например, П1). |
| Спецификация | Таблица с перечнем панелей: марка, размеры, количество, площадь. |

## AutoCAD
| Термин | Что означает |
|---|---|
| Плагин (надстройка) | Дополнительная программа, которая добавляет в AutoCAD новые команды и кнопки. |
| Команда | Действие AutoCAD, которое запускается кнопкой или вводом имени в командной строке. |
| Лента | Панель с вкладками и кнопками в верхней части окна AutoCAD. |
| Блок | Именованная группа объектов, которую можно вставлять много раз; может хранить атрибуты. |
| Атрибут блока | Текстовое свойство блока (например, марка или длина панели). |
| ID элемента (Handle, «Метка») | Постоянный номер объекта в чертеже, например `2A3F`. Виден в команде `СПИСОК`. |
| ObjectId | Внутренний номер объекта, действует только до закрытия AutoCAD. |
| NETLOAD | Команда AutoCAD для ручной загрузки плагина (.dll). |
| Bundle (.bundle) | Папка плагина с файлом `PackageContents.xml`; AutoCAD загружает её автоматически. |
| ApplicationPlugins | Папка, из которой AutoCAD автоматически загружает плагины при запуске. |
| APPAUTOLOAD | Системная переменная AutoCAD: разрешает автозагрузку плагинов из ApplicationPlugins. При значении 0 плагин не загружается. |
| Надёжное расположение (TRUSTEDPATHS) | Папка, из которой AutoCAD загружает программы без предупреждения безопасности. |
| SECURELOAD | Настройка AutoCAD, которая включает проверку надёжных расположений. |
| Динамический блок | Блок с параметрами и ручками: например, панель растягивается ручкой без взрыва блока. |
| Подсказка кнопки (RibbonToolTip) | Всплывающее окно у кнопки ленты: название, описание, имя команды и ссылка на справку по F1. |
| Поле (Field) | Текст, который AutoCAD вычисляет сам, например длина панели в марке. Обновляется при `РЕГЕН`, сохранении, открытии. |
| PK_Panel | Блок сэндвич-панели плагина: прямоугольник с ручками длины и ширины, марка «буква + длина в см» и скрытые данные для спецификации. |

## Разработка
| Термин | Что означает |
|---|---|
| Репозиторий | Папка проекта со всей историей изменений (git) и её копия на GitHub. |
| Коммит | Сохранённый шаг изменений с описанием, что и зачем сделано. |
| Ветка | Отдельная линия изменений; для каждой команды своя ветка. |
| master | Основная ветка: только проверенные и утверждённые изменения. |
| Слияние (merge) | Перенос изменений из ветки команды в master. |
| Push | Отправка локальных коммитов на GitHub. |
| Версия (A.B.C) | Номер версии плагина: A — глобальное обновление, B — изменения в командах для пользователя, C — служебные изменения. |
| Тег (v0.1.0) | Метка версии; по тегу GitHub создаёт релиз с установочным архивом. |
| Релиз (Release) | Страница версии на GitHub с архивом для скачивания. |
| GitHub Actions | Автоматическая сборка проекта на сервере GitHub. |
| Issue | Задача или сообщение об ошибке на GitHub. |
| .NET Framework 4.6 / 4.7 / 4.8 | Платформа, на которой работают плагины AutoCAD: 4.6 — AutoCAD 2018, 4.7 — AutoCAD 2020, 4.8 — AutoCAD 2021–2024. |
| Платформа AutoCAD (R23, R24) | Внутренний номер поколения AutoCAD. Плагин, собранный под одну платформу, работает во всех её версиях: R22.0 — AutoCAD 2018; R23.1 — AutoCAD 2020; R24 — AutoCAD 2021–2024. |
| `[CommandMethod]` | Отметка в коде C#, превращающая метод в команду AutoCAD. |
| CommandCatalog | Список всех команд плагина; по нему строится лента. |
