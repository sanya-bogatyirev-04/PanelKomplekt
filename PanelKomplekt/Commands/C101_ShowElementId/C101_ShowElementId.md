# C101_ShowElementId — ID выбранного элемента

| Параметр | Значение |
|---|---|
| Номер | C101 |
| Имя в AutoCAD | `PK_C101_SHOWELEMENTID` |
| Кнопка на ленте | вкладка «PanelKomplekt» → панель «Сервис» → «ID элемента» |
| Файл кода | [C101_ShowElementId.cs](C101_ShowElementId.cs) |
| Статус | тестовая |

## Назначение
Проверка работы плагина и ленты: показывает ID выбранного элемента чертежа.

## Алгоритм
1. Пользователь нажимает кнопку «ID элемента» или вводит `PK_C101_SHOWELEMENTID`.
2. В командной строке появляется запрос «Выберите элемент:».
3. Пользователь щёлкает по одному элементу (Esc — отмена, окно не показывается).
4. Открывается всплывающее окно: «ID выбранного элемента = &lt;ID&gt;».

## Входные данные
Один элемент чертежа, выбранный щелчком мыши.

## Результат
Всплывающее окно с ID. Чертёж не изменяется.

## Что является ID
Выводится дескриптор объекта (Handle) в шестнадцатеричном виде, например `2A3F`.
- Постоянен: не меняется после сохранения и повторного открытия чертежа.
- Совпадает со значением «Метка» в команде `СПИСОК` (`_LIST`).

ObjectId не используется: он действителен только в текущем сеансе AutoCAD.

## Ограничения и риски
- Выбирается ровно один элемент; рамкой несколько элементов выбрать нельзя.
- Для элемента внутри блока выводится ID вхождения блока, а не вложенного объекта.

## Как проверить
1. Выполнить команду и выбрать отрезок — появится окно с ID.
2. Выполнить `СПИСОК` для того же отрезка — «Метка» совпадает с ID в окне.
3. Выполнить команду и нажать Esc — окно не появляется, ошибок нет.
