# PanelKomplekt — инструкции для Claude

Плагин для AutoCAD 2020, 2021 и 2022 на C# (x64): раскладка сэндвич-панелей по фасадам и спецификация.
Две сборки из одного кода: net48 — AutoCAD 2021–2024 (R24), net47 — AutoCAD 2020 (R23.1).
Общайся с владельцем проекта на русском.

Обязательные правила проекта: @Docs/DevelopmentRules.md
Структура проекта: @Docs/ProjectStructure.md
