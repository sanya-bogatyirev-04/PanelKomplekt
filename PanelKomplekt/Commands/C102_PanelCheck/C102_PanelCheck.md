# C102_PanelCheck — проверка панелей

| Параметр | Значение |
|---|---|
| Номер | C102 |
| Имя в AutoCAD | `PK_C102_PANELCHECK` |
| Кнопка на ленте | вкладка «PanelKomplekt» → раздел «Панели» → «Проверка» |
| Файл кода | [C102_PanelCheck.cs](C102_PanelCheck.cs) |
| Статус | служебная |

## Назначение
Проверка работы с блоком панели `PK_Panel`: добавление определения блока в чертёж и чтение данных панелей
(марка, длина, ширина, тип, цвета). Нужна для проверки плагина и поиска ошибок в чертежах.

## Алгоритм
1. Пользователь нажимает «Проверка панелей» или вводит `PK_C102_PANELCHECK`.
2. Если в чертеже нет блока `PK_Panel`, он копируется из файла-шаблона `Blocks\PK_Panel.dwg` рядом с DLL плагина.
   В командной строке пишется, был ли блок в чертеже или добавлен.
3. Запрос «Выберите панели для проверки»: выбрать объекты (рамкой, щелчками) или нажать Enter — будут взяты все панели пространства модели.
4. Для каждой панели выводится строка: ID, марка, длина и ширина в мм, тип, RAL и покрытие снаружи и внутри.
   Прочие объекты в выборе пропускаются.

## Входные данные
Панели — вставки блока `PK_Panel` (в том числе растянутые: такие вставки AutoCAD хранит как анонимные блоки `*U…`).

## Результат
Сообщения в командной строке, например:
```
Блок PK_Panel уже есть в чертеже.
Найдено панелей: 2 (прочих объектов пропущено: 3)
  ID 2B1: П598  длина 5980 × ширина 1190 мм  тип «ПСБ-120»  снаружи 3005/накатка  внутри 9003/накатка
  ID 2C4: П620  длина 6200 × ширина 1190 мм  тип «ПСБ-120»  снаружи 3005/накатка  внутри 9003/накатка
```
Предупреждения в строке панели: `[!] длиннее 13600 мм`, `[!] пустая буква марки`, `[!] пустой тип`.

## Ограничения и риски
- Чертёж не изменяется, кроме добавления определения блока `PK_Panel`, если его не было.
- Существующее определение блока в чертеже не перезаписывается.
- Построчно выводится не больше 200 панелей.

## Как проверить
1. Новый пустой чертёж → команда → «Блок PK_Panel добавлен в чертёж из шаблона» → Enter → «Найдено панелей: 0».
2. Повторно → «Блок PK_Panel уже есть в чертеже».
3. `ВСТАВИТЬ` → `PK_Panel`, растянуть до 6200 → команда → выбрать панель → «П620 длина 6200 × ширина 1190».
4. Выбрать рамкой панели вместе с другими объектами → панели найдены, прочие пропущены.
