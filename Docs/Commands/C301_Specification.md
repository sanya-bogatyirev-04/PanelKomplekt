# C301. Составить

| Параметр | Значение |
|---|---|
| Кнопка на ленте | **PanelKomplekt → Спецификации → Составить** |
| Имя команды в AutoCAD | `PK_C301_SPECIFICATION` |
| Изменяет чертёж | Только при выборе «Таблица» или «Оба»: добавляет таблицу на текущий слой |

## Назначение

Считает панели, созданные командой [«Создание»](C201_InsertPanel.md), и формирует спецификацию:

- файлом Excel (`.xlsx`);
- таблицей AutoCAD в чертеже;
- или обоими способами сразу.

## Перед началом

1. Проверьте, что у панелей заполнены буква марки и тип (двойной щелчок по панели).
2. Если нужна спецификация одного фасада — приготовьтесь выбрать его панели рамкой.
3. Для таблицы в чертеже сделайте текущими нужный слой и стиль таблиц.
4. Если файл спецификации с тем же именем открыт в Excel — закройте его.

## Порядок работы

1. Нажмите **Спецификации → Составить** или введите `PK_C301_SPECIFICATION`.
2. Выберите панели рамкой или щелчками и нажмите **Enter**. Чтобы посчитать все панели чертежа,
   сразу нажмите **Enter**.
3. В командной строке появится итог и предупреждения, если они есть.
4. На запрос `Результат` выберите **Excel**, **Таблица** или **Оба**.
5. Для Excel укажите папку и имя файла и нажмите **Сохранить** — файл откроется сам.
6. Для таблицы укажите точку левого верхнего угла таблицы в чертеже.

## Запросы и параметры

### Выбор панелей

```
Выберите панели для спецификации <Enter — все панели в модели>:
```

| Ввод | Что попадёт в спецификацию |
|---|---|
| Enter без выбора | Все панели пространства модели (панели на листах не учитываются) |
| Рамка, секущая рамка, щелчки, затем Enter | Только выбранные панели |
| Esc | Команда завершается, ничего не считается |

Вместе с панелями можно захватить любые другие объекты — линии, размеры, блоки: они не учитываются.

### Итог в командной строке

```
Панелей: 330, типов: 1, площадь: 2 364,31 м².
```

Ниже — строки предупреждений с пометкой `[!]`, если они есть.

### Вид результата

```
Результат [Excel/Таблица/Оба] <Excel>:
```

| Ввод | Результат |
|---|---|
| Enter или `E` (Excel) | Файл `.xlsx`, открывается сразу после сохранения |
| `Т` (Таблица) | Таблица AutoCAD в чертеже |
| `О` (Оба) | И файл, и таблица |
| Esc | Команда завершается, результат не создаётся |

### Сохранение файла Excel

Открывается стандартное окно сохранения.

| Параметр | По умолчанию |
|---|---|
| Имя файла | `<имя чертежа>_Спецификация.xlsx` |
| Папка | Папка чертежа; если чертёж не сохранён — «Документы» |

Если нажать **Отмена**, файл не создаётся, в командной строке появится `Сохранение в Excel отменено.`
Для автоматического открытия нужен Excel или другая программа для `.xlsx`. Если её нет, файл всё равно
сохраняется, а в командной строке появится `Файл сохранён, но открыть его автоматически не удалось.`

### Точка вставки таблицы

```
Левый верхний угол таблицы спецификации:
```

Таблица создаётся на текущем слое с текущим стилем таблиц.

## Состав спецификации

### Группы

Панели делятся на группы. В одну группу попадают панели с одинаковыми типом, шириной, RAL и покрытием
снаружи, RAL и покрытием внутри. Группы отсортированы по типу, затем по ширине.
Заголовок группы выглядит так:

```
1. Панели ПСБ-120 ширина 1190 мм.
```

### Строки и столбцы

Внутри группы одна строка — одна марка с одной длиной. Строки отсортированы по длине от большей к меньшей.

| Столбец | Содержание |
|---|---|
| № | Марка, например П598 |
| Стальные поверхности панелей → Наружная → RAL | RAL снаружи |
| Стальные поверхности панелей → Наружная → Вид поверх. | Покрытие снаружи |
| Стальные поверхности панелей → Внутренняя → RAL | RAL внутри |
| Стальные поверхности панелей → Внутренняя → Вид поверх. | Покрытие внутри |
| Длина, мм | Длина панели |
| Кол-во, шт. | Количество панелей |
| Площадь, м² | Площадь панелей строки |

После строк группы идёт строка **«ИТОГО:»** — количество и площадь по этой группе.
В конце спецификации — строка **«ИТОГО по всем типам:»**.

### Расчёт площади

```
Площадь строки = Кол-во × Длина (м) × Ширина (м)
```

Результат округляется до 0,01 м². Итоги — сумма площадей строк.
Пример: 284 × 5,98 × 1,19 = 2 020,99 м².

### Пример

**1. Панели ПСБ-120 ширина 1190 мм.**

| № | Наружная RAL | Вид поверх. | Внутренняя RAL | Вид поверх. | Длина, мм | Кол-во, шт. | Площадь, м² |
|---|---|---|---|---|---|---|---|
| П631 | 3005 | накатка | 9003 | накатка | 6310 | 30 | 225,27 |
| П620 | 3005 | накатка | 9003 | накатка | 6200 | 16 | 118,05 |
| П598 | 3005 | накатка | 9003 | накатка | 5980 | 284 | 2 020,99 |
| **ИТОГО:** | | | | | | **330** | **2 364,31** |

### Оформление Excel

- Один лист «Спецификация», альбомная ориентация.
- Объединённые ячейки трёхуровневой шапки и заголовков групп, рамки, жирная шапка и итоги.
- Числа записаны числами, а не текстом: их можно суммировать и использовать в формулах.
- Длина и количество — целые, площадь — с двумя знаками после запятой.
- RAL записан текстом, поэтому ведущие нули и запись вида `3005` не искажаются.

## Предупреждения

Спецификация формируется и при наличии предупреждений, но их стоит проверить.

| Предупреждение | Причина | Что сделать |
|---|---|---|
| `Панели длиннее 13600 мм (N шт.), ID: …` | Панель растянута за допустимый предел | Найти панель по ID командой [«Поиск»](C101_ShowElementId.md), уменьшить длину или разбить на две панели |
| `Панели без буквы марки (N шт.), ID: …` | Не заполнен атрибут PREFIX | Двойной щелчок по панели, заполнить букву |
| `Панели без типа (N шт.), ID: …` | Не заполнен атрибут TYPE | Двойной щелчок по панели, заполнить тип |
| `Марка … у панелей разной длины: … мм` | Например, 5980 и 5984 мм дают одну марку П598, но идут разными строками | Привести длины к одному значению, кратному 10 мм (палитра «Свойства», поле **Length**) |

## Ограничения

- Учитываются только вставки блока `PK_Panel`. Расчленённые панели и панели с переименованным блоком
  не считаются.
- Enter без выбора берёт панели **только из пространства модели**.
- Таблица в чертеже не связана с панелями: после изменения панелей её нужно создать заново.
- Площадь считается по прямоугольнику: вырезы и косые резы не учитываются.
- Панели с одинаковой маркой, но разной длиной идут отдельными строками.

## Результат

- Файл `.xlsx` в указанной папке — для отправки заказчику и подсчётов;
- и/или таблица AutoCAD в чертеже на текущем слое;
- итог и предупреждения в командной строке.

## Возможные ситуации и что делать

| Ситуация | Что делать |
|---|---|
| `Панели PK_Panel не найдены.` | Среди выбранного нет панелей. Выберите другую область или нажмите Enter для всех панелей модели |
| `Не удалось записать файл …: он открыт в другой программе.` | Закройте файл в Excel и повторите или сохраните под другим именем |
| `Файл сохранён, но открыть его автоматически не удалось.` | Откройте файл вручную; на компьютере нет программы для `.xlsx` |
| Панель не попала в спецификацию | Проверьте в палитре «Свойства», что объект — блок `PK_Panel` и лежит в пространстве модели |
| Суммы в Excel и в таблице чертежа различаются | Они сделаны в разное время или по разным наборам панелей. Создайте спецификацию заново с вариантом «Оба» |
| Таблица в чертеже устарела | Таблица не обновляется автоматически: удалите её и запустите команду снова |
| Таблица получилась слишком мелкой или крупной | Размер текста берётся из настроек команды в миллиметрах чертежа; масштабируйте таблицу стандартной командой МАСШТАБ |
