# C100_About — сведения о плагине

| Параметр | Значение |
|---|---|
| Номер | C100 |
| Имя в AutoCAD | `PK_C100_ABOUT` |
| Кнопка на ленте | вкладка «PanelKomplekt» → панель «Сервис» → «О плагине» |
| Файл кода | [C100_About.cs](C100_About.cs) |
| Статус | служебная |

## Назначение
Проверка, что плагин загружен, и вывод его версии.

## Алгоритм
1. Пользователь нажимает кнопку «О плагине» или вводит `PK_C100_ABOUT`.
2. В командную строку выводится название и версия плагина.

## Входные данные
Не требуются.

## Результат
Строка в командной строке: `PanelKomplekt <версия> — раскладка сэндвич-панелей и спецификация.`

## Ограничения и риски
- Чертёж не изменяется.
- Раньше команда называлась `PK_INFO`; старое имя больше не работает.

## Как проверить
Выполнить команду: в командной строке появится название и версия плагина.
