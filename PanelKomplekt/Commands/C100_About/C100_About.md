# C100_About — сведения о плагине

| Параметр | Значение |
|---|---|
| Номер | C100 |
| Имя в AutoCAD | `PK_C100_ABOUT` |
| Кнопка на ленте | вкладка «PanelKomplekt» → раздел «Сервис» → «О плагине» |
| Файл кода | [C100_About.cs](C100_About.cs) |
| Инструкция пользователя | [Docs/Commands/C100_About.md](../../../Docs/Commands/C100_About.md) |
| Статус | служебная |

## Назначение
Показывает сведения о плагине: версию, для кого и кем он создан, на каких технологиях сделан.

## Алгоритм
1. Пользователь нажимает кнопку «О плагине» или вводит `PK_C100_ABOUT`.
2. В командную строку выводится название и версия плагина (удобно скопировать в сообщение об ошибке).
3. Открывается окно «О плагине PanelKomplekt» с кнопкой OK.

## Входные данные
Не требуются.

## Результат
Окно со сведениями:
```
PanelKomplekt, версия 0.3.0
Плагин создан для оптимизации и упрощения работы сотрудников ООО «Панелькомплект»

Создан для: ООО «Панелькомплект»
Разработчик: Богатырев Александр Дмитриевич

Технологии:
  • C# и .NET Framework 4.8
  • AutoCAD .NET API (AutoCAD 2021)
  • WPF — вкладка и кнопки на ленте
  • Visual Studio 2022, Git, GitHub Actions
```
Версия берётся из сборки автоматически. Заказчик, разработчик и технологии задаются в `Core/PluginInfo.cs`.

## Ограничения и риски
- Чертёж не изменяется.
- Раньше команда называлась `PK_INFO`; старое имя больше не работает.

## Как проверить
1. Нажать «О плагине» — открывается окно с текстом выше, версия совпадает с `<Version>` в `PanelKomplekt.csproj`.
2. Окно находится поверх AutoCAD; пока оно открыто, AutoCAD не реагирует на щелчки.
3. OK закрывает окно, в командной строке остаётся строка с версией.
