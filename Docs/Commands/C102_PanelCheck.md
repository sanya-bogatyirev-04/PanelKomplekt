# C102. Проверка

| Параметр | Значение |
|---|---|
| Кнопка на ленте | **PanelKomplekt → Панели → Проверка** |
| Имя команды в AutoCAD | `PK_C102_PANELCHECK` |
| Изменяет чертёж | Да, но только один раз: добавляет определение блока `PK_Panel`, если его нет. Сами панели не меняются |

## Назначение

Показывает, какие данные хранит каждая панель: марку, длину, ширину, тип, RAL и покрытия.
Команда нужна, чтобы проверить панели **до** составления спецификации и заранее найти те,
из-за которых появятся предупреждения.

Заодно команда добавляет в чертёж определение блока `PK_Panel`, если его там ещё нет.

## Перед началом

Откройте чертёж с панелями. Если панелей ещё нет, команда всё равно полезна: она добавит блок
в чертёж, и панель можно будет вставить обычной командой `ВСТАВИТЬ`.

## Порядок работы

1. Нажмите **Панели → Проверка** или введите `PK_C102_PANELCHECK`.
2. Прочитайте первую строку: есть ли блок панели в чертеже или он только что добавлен.
3. Выберите панели рамкой или щелчками и нажмите **Enter**. Чтобы проверить все панели чертежа,
   сразу нажмите **Enter**.
4. Прочитайте список в командной строке. Если он не помещается, нажмите **F2** — откроется
   текстовое окно с полным протоколом.

## Запросы и параметры

```
Выберите панели для проверки <Enter — все панели в модели>:
```

| Ввод | Что проверяется |
|---|---|
| Enter без выбора | Все панели пространства модели |
| Рамка, секущая рамка, щелчки, затем Enter | Только выбранные панели |
| Esc | Команда завершается |

Посторонние объекты в рамке не мешают: команда сообщит, сколько объектов пропущено.

### Что выводится

```
Блок PK_Panel уже есть в чертеже.
Найдено панелей: 3 (прочих объектов пропущено: 12)
  ID 2A7F: П598  длина 5980 × ширина 1190 мм  тип «ПСБ-120»  снаружи 3005/накатка  внутри 9003/накатка
```

| Пометка в строке | Что означает |
|---|---|
| `[!] длиннее 13600 мм` | Панель растянута за допустимый предел |
| `[!] пустая буква марки` | Не заполнен атрибут PREFIX |
| `[!] пустой тип` | Не заполнен атрибут TYPE |

Номер в начале строки — ID панели. По нему панель можно найти в чертеже:
см. [«Поиск»](C101_ShowElementId.md), раздел «Обратная задача».

## Ограничения

- В командную строку выводится не больше **200** панелей, остальные считаются, но не перечисляются:
  в конце появится строка `… и ещё N`.
- Enter без выбора берёт панели только из пространства модели.
- Команда ничего не исправляет: она только показывает данные.
- Существующее в чертеже определение блока `PK_Panel` не заменяется шаблоном плагина.

## Результат

Список панелей в командной строке. Чертёж не меняется, кроме однократного добавления определения
блока `PK_Panel`.

## Возможные ситуации и что делать

| Ситуация | Что делать |
|---|---|
| `Не найден файл блока … Переустановите плагин` | Закройте AutoCAD, выполните `Uninstall.cmd`, затем `Install.cmd` |
| `Найдено панелей: 0` | Среди выбранного нет панелей: либо выбраны другие объекты, либо панели расчленены или лежат на листе |
| Список не помещается в командной строке | Нажмите F2 и прочитайте полный протокол в текстовом окне |
| У панели пометка `[!]` | Исправьте данные двойным щелчком по панели или измените длину в палитре «Свойства» |
| Данные панели отличаются от ожидаемых | Панель могли скопировать из другого чертежа: проверьте атрибуты двойным щелчком |
