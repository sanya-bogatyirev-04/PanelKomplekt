# C101. Поиск

| Параметр | Значение |
|---|---|
| Кнопка на ленте | **PanelKomplekt → Элементы → Поиск** |
| Имя команды в AutoCAD | `PK_C101_SHOWELEMENTID` |
| Изменяет чертёж | Нет |

## Назначение

Показывает **идентификатор (ID)** выбранного объекта — постоянный номер объекта в чертеже.
Он не меняется при сохранении и повторном открытии файла и совпадает со строкой «Метка»
стандартной команды `СПИСОК`.

Команда нужна, когда:

- в предупреждении команды [«Составить»](C301_Specification.md) указан ID проблемной панели,
  и эту панель нужно найти в чертеже;
- разработчик просит сообщить ID объекта, на котором возникла ошибка.

## Перед началом

Откройте чертёж с объектом, ID которого нужно узнать. Ничего выделять заранее не требуется.

## Порядок работы

1. Нажмите **Элементы → Поиск** или введите `PK_C101_SHOWELEMENTID` в командной строке.
2. На запрос `Выберите элемент:` щёлкните по нужному объекту.
3. Прочитайте номер в окне **«ID выбранного элемента = …»** и нажмите **OK**.

## Запросы и параметры

```
Выберите элемент:
```

| Ввод | Действие |
|---|---|
| Щелчок по объекту | Показать его ID |
| Esc | Завершить команду без вывода ID |

Выбирается ровно один объект: рамкой выбрать нельзя.

## Обратная задача: найти объект по известному ID

Чтобы выделить в чертеже объект с известным ID, введите в командной строке строку ниже,
заменив `2A7F` на нужный номер, и нажмите Enter:

```
(sssetfirst nil (ssadd (handent "2A7F")))
```

Вводите её, когда никакая другая команда не выполняется. Объект будет выделен ручками.
Чтобы показать его на экране, введите `ПОКАЗАТЬ`, выберите опцию **оБъект** и нажмите Enter.

## Ограничения

- Если щёлкнуть по объекту внутри блока, команда покажет ID **вставки блока**, а не объекта внутри неё.
- ID действует только в пределах одного чертежа: в другом файле тот же номер принадлежит другому объекту.
- Команда ничего не ищет по номеру — для этого используйте строку из раздела выше.

## Результат

Окно с идентификатором, например `ID выбранного элемента = 2A7F`. Чертёж не изменяется.

## Возможные ситуации и что делать

| Ситуация | Что делать |
|---|---|
| Выбор отменён клавишей Esc | Команда завершилась, окно не появится — запустите её снова |
| Щелчок не попал по объекту | AutoCAD повторит запрос; увеличьте масштаб и щёлкните точно по линии объекта |
| Показан ID блока, а нужен объект внутри | Войдите в блок двойным щелчком или расчлените копию блока в стороне от чертежа |
| Объект по ID не находится строкой поиска | Объект удалён, либо номер относится к другому чертежу |
